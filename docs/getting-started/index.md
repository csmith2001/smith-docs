# Welcome to Smith Docs!

Welcome to the Smith Lab documentation.

This section contains the foundational guides used throughout the project.
These documents explain the documentation standards, site tooling, and
technologies used to maintain and publish the documentation.

---

## Included Guides

### Markdown in 5 Minutes

Learn the Markdown syntax used throughout the documentation, including
formatting, code blocks, tables, links, images, and admonitions.

### Zensical in 5 Minutes

Learn how the documentation site is built, configured, previewed,
and published using Zensical.

---

## Purpose

The goal of this section is to provide enough information to:

- Navigate the documentation
- Understand how documentation is written
- Contribute new content
- Maintain the documentation platform

!!! tip

    New contributors should start with **Markdown in 5 Minutes**
    followed by **Zensical in 5 Minutes**.
