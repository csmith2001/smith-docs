# Fedora Linux

Fedora is the primary Linux distribution used throughout Smith Lab.
This section contains installation media preparation guides,
operating system deployment procedures, workstation standards,
server deployment guidance, and Fedora-specific tooling.

!!! info

    Unless otherwise noted, all installation guides assume
    Fedora is the target operating system.
