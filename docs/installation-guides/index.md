# Installation Guides

This section contains installation and deployment procedures
used throughout Smith Lab.

Guides are organized by operating system and software category,
with an emphasis on repeatability, validation, and recovery.

---

## Operating Systems

Operating system installation media and deployment procedures.

Topics include:

- Linux distributions
- Installation media creation
- Workstation deployments
- Server deployments
- Virtual machine deployments

---

## Software

Software installation and configuration guides used throughout the lab environment.

Topics include:

- Operating system utilities
- Development tools
- Editors and IDEs
- Supporting applications

!!! note

    Installation guides focus on achieving a working and validated deployment.
    Environment-specific configuration should be documented separately
    where practical.
